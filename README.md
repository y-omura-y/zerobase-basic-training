# ゼロベース開発のための基礎練習

## 概要

React の基礎を身につけるための練習用リポジトリ  
笠間さんのアドバイスを参考に、3つのアプリを順番に作成していく

## 目的

- React の基本を理解する
- コンポーネント分割に慣れる
- props / state / イベント処理を学ぶ
- 自分で調べながら実装する力をつける
- Gitの基本的な開発フローに慣れる

## 学習ステップ

1. 電卓アプリ
   - JSX
   - props
   - イベント処理
   - useState
   - CSS Modules

2. Todoアプリ
   - 配列の状態管理
   - 追加・表示・更新・削除（CRUD）
   - localStorage（余裕があれば）

3. APIを利用したアプリ
   - API通信
   - ローディング表示
   - エラーハンドリング
   - 取得データの表示

## 進め方

各アプリごとに feature ブランチを作成し、実装後に Pull Request を作成して main にマージ

feature/calculator
feature/todo-app
feature/api-app
